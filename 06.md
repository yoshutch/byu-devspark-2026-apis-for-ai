# Who is allowed to schedule this appointment?

The API is clearer now—but is it safe to invoke?

- Can anyone call the endpoint?
- How does the API know who is making the request?
- Is the caller acting for themselves or for someone else?
- What is this caller allowed to do?
- What should happen when the caller is authenticated but not authorized?
- Can we tell who made the request and what happened afterward?
