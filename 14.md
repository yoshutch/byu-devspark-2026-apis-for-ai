# Can a client discover the contract?

The rules now exist—but are they visible to the people and machines that need them?

- How does a new developer find the API?
- How does a generated client know the request and response shapes?
- How does an AI agent discover available operations?
- Where are valid enum values documented?
- Where are authentication, idempotency, rate-limit, and error behaviors described?
- How does a client know which version is current?

> [!Important] 
> Tribal knowledge is not an API contract.
