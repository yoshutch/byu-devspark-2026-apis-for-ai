# What does this API actually promise?

## Meaning

- Which advisor is being scheduled?
- What does `type: "advisor"` mean?
- Is `byuId` the student's or the advisor's ID?

## Time

- What date does “tomorrow” mean?
- What time zone does “5pm” use?
- Is the appointment requested, reserved, or confirmed?

## Behavior

- What happens if two clients select the same time slot?
- Does the API send a confirmation email?
- What happens if the request times out and the client retries?

>[!Note] 
> The endpoint may be easy for someone familiar with the system, but the contract leaves too much to inference.
