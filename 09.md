# Make retries safe

Give each intended operation a stable identity:

```http
POST /advisement/appointments
Idempotency-Key: 8f7c2d91-appointment-request-123
Content-Type: application/json

{
  "student_id": "123456789",
  "advisor_id": "111111111",
  "appointment_type": "academic_advising",
  "starts_at": "2026-12-25T17:00:00-07:00"
}
```

The API records the result for that key:

- First request: create the appointment.
- Retry with the same key: return the original result.
- Same key with different data: reject the request.
- New key: represent a new appointment attempt.

> [!IMPORTANT]
> A retry should not accidentally become a second business operation.
