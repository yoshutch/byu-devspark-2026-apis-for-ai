# What if two clients request the same slot?

Idempotency protects one operation from being duplicated.

It does not prevent two different clients from requesting the same slot.

```text
Client A ── request 5:00 PM ──▶ API
Client B ── request 5:00 PM ──▶ API
```

- Which request should succeed?
- What should happen to the other request?
- Can both clients understand what happened?
- How does the API enforce the business rule?

**Business rule:** An advisor cannot have two appointments in the same time slot.
