# What if a client calls too aggressively?

Even an authorized client can call an endpoint too frequently.

```text
Client or AI agent
        │
        ├─ request
        ├─ request
        ├─ request
        ├─ request
        └─ request ...
                │
                ▼
        Calendar service / API
```

- Could repeated requests overload the API?
- Could they overload the calendar system behind it?
- What if an agent retries in a tight loop?
- How does the client know when to try again?
