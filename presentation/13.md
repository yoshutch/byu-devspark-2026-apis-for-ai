# Protect the API with rate limits

Rate limits protect the API and the systems behind it from excessive traffic.

When a client exceeds its limit, respond explicitly:

```http
429 Too Many Requests
Retry-After: 10
Content-Type: application/problem+json

{
  "type": "http://localhost:8080/problems/rate-limit-exceeded",
  "title": "Rate limit exceeded",
  "status": 429,
  "code": "RATE_LIMIT_EXCEEDED",
  "detail": "Too many requests from this client. Retry after 10 seconds."
}
```

The client now knows:

- the request was rejected temporarily;
- it should wait before trying again;
- it should not retry in a tight loop.

> [!Important]
> A limit is more useful when the client knows what to do next.
