# Is it safe to retry?

Imagine this sequence:

```text
Client  ── POST /advisement/appointments ──▶  API
                                             │
                                             ├─ Appointment created
                                             └─ Response lost

Client  ── retries the request ────────────▶  API
```

What should happen?

- Does the API create a second appointment?
- Does it return the appointment that was already created?
- Does it return a conflict?
- Can the client tell whether the first request succeeded?

An AI agent faces the same uncertainty—but may retry without understanding the business consequence.

> [!Important] 
> Clear meaning is not enough. A durable contract must also define retry behavior.
