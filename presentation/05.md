# Make the meaning explicit

Start with a meaningful domain resource and explicit values:

```http
POST /advisement/appointments
Content-Type: application/json

{
  "student_id": "123456789",
  "advisor_id": "111111111",
  "appointment_type": "academic_advising",
  "starts_at": "2026-10-08T17:00:00-07:00"
}
```

This is already better:

- The resource and operation are understandable.
- The student and advisor are not confused.
- The appointment type has a meaningful value.
- The timestamp includes a date, time, and time zone.
