# Can a machine safely use it?

A conventional client can send this request.

But can it use the API correctly?

- Can a generated client know what values are valid?
- Can an AI agent determine which advisor and appointment type to use?
- What should it do when the request times out?
- Is it safe to retry?
- Should it ask for clarification—or guess?

> [!Important]
> Machines should not have to invent missing parts of the contract.
